# Roueba-agente

App web estática de prueba, adaptable a teléfonos. Incluye un botón interactivo
para comprobar que la app responde al tacto.

## Publicación

Cada cambio en `main` publica el sitio en GitHub Pages mediante la acción
`.github/workflows/pages.yml`. La URL es:

https://luischidalgo.github.io/Roueba-agente/
